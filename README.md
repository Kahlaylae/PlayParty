# Play Party Online

**[playparty.online](https://playparty.online)** hosts original, self-made games available for free. Play directly in your browser—no downloads required.

## Games

### Emoji Hunter
Bluey was just a block of stinky tofu waiting to be thrown into a hot pot. One night, he gets dropped onto the neon streets of Japan. Now he must defend against mobs of emoji monsters, zombies, and freaky demons. Stay alive as long as you can!

- **Genre:** Casual scrolling shooter
- **Platform:** Web browser (desktop + mobile)
- **Status:** Live

## Tech Stack
- Vanilla JavaScript
- HTML5 Canvas
- CSS3
- No frameworks, no dependencies
